# Animal Raid

Jeu de Noël en 3D pour iPad : luge, canoë et deltaplane. Jouable directement dans Safari, même hors ligne.

**Jouer :** https://fhdu003.github.io/animal-raid/

Sur iPad : ouvrir le lien dans Safari, puis Partager → « Sur l'écran d'accueil ».

Ce dépôt ne contient que la version jouable. Crédits des modèles 3D : voir `CREDITS.txt`.

Pour tester avec tout débloqué (sauvegarde séparée, la vraie partie n'est pas touchée) : https://fhdu003.github.io/animal-raid/?tout

Pour remettre la vraie partie à zéro sur un appareil : https://fhdu003.github.io/animal-raid/?reset

**Jeu de piste « Cadeau Maxime » :** https://fhdu003.github.io/animal-raid/cadeau/ (six énigmes qui mènent au jeu). Pour le recommencer depuis le début : https://fhdu003.github.io/animal-raid/cadeau/?reset
